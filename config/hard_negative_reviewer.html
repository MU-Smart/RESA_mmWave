Hard Negative Reviewer

Frame-level annotation tool for mining false-positive humans from mmWave replay artifacts. Exports corrected per-frame labels for KPConv retraining.

A Load session folder (recommended)

Select the debug_frame_samples directory. App scans for all debug_frames.json manifests and PNG images automatically.

B Load mining JSON + images

Select hard_negative_candidates.json (from 3branch_hard_negative_mining.py), then select the images folder separately.

C Resume prior review (optional)

Load a previously exported review JSON to merge annotations with the current import.

D Load LLM auto-labels (optional)

Load an auto_labels.csv produced by hnm_autolabel.py. Each frame's LLM decision pre-fills the review form — you confirm or override.

State auto-saves to localStorage (hnr_v1). Restore previous session?
